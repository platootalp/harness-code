# Using Superpowers

## Core Rule

Before taking any action, invoke relevant skills—even if there's just a 1% chance one might apply.

## How to Use Skills

- In Claude Code: Use the `Skill` tool
- In Copilot CLI: Use the `skill` tool
- In Gemini CLI: Use the `activate_skill` tool

## Red Flags

- "This is just a simple question" → Questions are tasks, check for skills
- "Let me explore first" → Skills tell you HOW to explore
- "I'll just do this one thing first" → Check BEFORE doing anything

## Priority Order

1. User instructions (highest)
2. Superpowers skills
3. Default system prompt (lowest)

## Skill Types

- **Rigid skills** (TDD, debugging): Follow exactly
- **Flexible skills** (patterns): Adapt to context

If you think there's even a small chance a skill applies, invoke it.
