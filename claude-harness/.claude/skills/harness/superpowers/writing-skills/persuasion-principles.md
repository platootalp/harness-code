# Persuasion Principles for Skill Design

## The Seven Principles

### 1. Authority
Imperative language: "YOU MUST", "Never", "Always"
Eliminates decision fatigue and rationalization.

### 2. Commitment
Require announcements: "Announce skill usage"
Force explicit choices and use tracking.

### 3. Scarcity
Time-bound requirements: "Before proceeding"
Sequential dependencies prevent procrastination.

### 4. Social Proof
Universal patterns: "Every time", "Always"
Establishes norms for common failures.

### 5. Unity
Collaborative language: "our codebase", "we're colleagues"
Shared goals create team culture.

### 6. Reciprocity
Use sparingly - can feel manipulative.

### 7. Liking
**DON'T USE for compliance** - creates sycophancy.

## By Skill Type

| Skill Type | Use | Avoid |
|------------|-----|-------|
| Discipline-enforcing | Authority + Commitment + Social Proof | Liking |
| Guidance/technique | Moderate Authority + Unity | Heavy authority |
