# Visual Companion Guide

This documentation describes a browser-based visual brainstorming tool for showing mockups, diagrams, and options during collaborative sessions.

**Key Points:**
- Use the browser for UI mockups, architecture diagrams, visual comparisons
- Use the terminal for text-based content, requirements, conceptual choices
- Start a session via `scripts/start-server.sh` with `--project-dir` for persistence
- Write HTML content fragments to `screen_dir`
- Check `state_dir/events` for user browser interactions
- Push "waiting.html" to clear stale content
