## 1. 概述

### 1.1 模块名称

Config（配置管理）

### 1.2 职责

Config 模块是 Mozi 系统的核心基础设施层组件，负责：
- 管理应用配置（JSON 格式）
- 配置加载与校验（JSON Schema 验证）
- 环境变量注入（运行时动态替换）
- 配置热更新（无需重启应用）

### 1.3 核心能力

| 能力 | 说明 |
| ---- | ---- |
| JSON 配置加载 | 从指定路径加载 JSON 配置文件 |
| Schema 校验 | 使用 JSON Schema 验证配置合法性 |
| 环境变量注入 | 支持 `${ENV_VAR}` 语法注入环境变量 |
| 热更新 | 监听文件变化，自动重载配置 |
| 多环境支持 | 支持 development/staging/production 环境配置 |
| 配置合并 | 支持 base + override 配置合并策略 |

## 2. 核心问题与解决方案

### 2.1 配置格式不统一与校验缺失

**问题描述**：不同环境、不同模块使用不同配置格式，缺乏统一规范和校验机制。当配置错误时，错误往往在运行时才被发现，难以定位根因。

**挑战**：配置结构复杂，Schema 需要覆盖所有边界情况，同时要保持足够的灵活性。传统错误处理方式难以覆盖所有配置场景。

**解决方案**：采用 JSON Schema Draft 7 标准进行配置验证，支持嵌套引用和自定义规则。所有配置必须通过 Schema 校验才能加载，校验失败时抛出明确的错误信息和错误位置。

### 2.2 敏感信息泄露风险

**问题描述**：密钥等敏感信息直接写在配置文件中，存在安全风险。环境变量注入时需要避免注入攻击，确保变量替换后格式正确。

**挑战**：需要在安全性和易用性之间取得平衡。环境变量注入过程可能被恶意利用。

**解决方案**：统一使用 `${ENV_VAR}` 和 `${ENV_VAR:default}` 语法进行环境变量注入，在加载时进行格式验证和安全检查。敏感配置通过环境变量注入，不存储在配置文件中。

### 2.3 配置不可热更新

**问题描述**：修改配置需要重启应用，影响系统可用性。配置重载过程中可能出现不一致状态。

**挑战**：热更新机制需要保证原子性，避免在重载过程中出现不一致状态。同时要考虑配置文件不存在或格式错误的情况。

**解决方案**：使用 mtime 监测文件变化，验证通过后原子性重载配置。新配置校验通过后才生效，失败时使用旧配置继续运行，通过 EventBus 通知变更。

### 2.4 多环境配置切换复杂

**问题描述**：不同环境（development/staging/production）的配置差异需要有效管理，避免在不同环境间切换时出现配置错误。

**挑战**：需要在不同环境间无缝切换，同时保持配置的复用性和可维护性。

**解决方案**：支持 base + override 配置合并策略，base 配置包含通用设置，override 配置包含环境特定设置。深度合并算法确保环境特定配置正确覆盖基础配置。

## 3. 数据模型

### 3.1 核心类型定义

```python
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any


class ConfigError(Exception):
    """Config 模块基础异常"""

    def __init__(self, code: str, message: str) -> None:
        self.code = code
        super().__init__(message)


class ConfigValidationError(ConfigError):
    """配置校验失败"""
    def __init__(self, message: str, errors: list[str] | None = None) -> None:
        super().__init__("Cfg_001", f"Validation failed: {message}")
        self.errors = errors or []


class ConfigNotFoundError(ConfigError):
    """配置文件不存在"""
    def __init__(self, path: str) -> None:
        super().__init__("Cfg_002", f"Config file not found: {path}")


class ConfigLoadError(ConfigError):
    """配置加载失败"""
    def __init__(self, path: str, cause: str) -> None:
        super().__init__("Cfg_003", f"Failed to load config from {path}: {cause}")


@dataclass
class AppConfig:
    """应用配置"""
    version: str
    environment: str = "development"
    app: dict[str, Any] = field(default_factory=dict)
    model: dict[str, Any] = field(default_factory=dict)
    session: dict[str, Any] = field(default_factory=dict)
    tools: dict[str, Any] = field(default_factory=dict)
    security: dict[str, Any] = field(default_factory=dict)

    def get(self, key: str, default: Any = None) -> Any:
        """获取配置值，支持点号分隔路径"""
        keys = key.split(".")
        value = self.__dict__
        for k in keys:
            if isinstance(value, dict):
                value = value.get(k)
            else:
                return default
            if value is None:
                return default
        return value
```

## 5. 接口与交互

### 5.1 核心接口定义

```python
from abc import ABC, abstractmethod


class BaseConfigLoader(ABC):
    """配置加载器抽象基类"""

    @abstractmethod
    async def load(self, config_path: str | Path) -> AppConfig:
        """加载配置"""
        raise NotImplementedError

    @abstractmethod
    async def validate(self, config: dict[str, Any]) -> list[str]:
        """校验配置，返回错误列表"""
        raise NotImplementedError


class ConfigAccessor:
    """配置访问器（单例模式）"""

    _instance: "ConfigAccessor | None" = None

    def __init__(self, config: AppConfig) -> None:
        self._config = config

    @classmethod
    def initialize(cls, config: AppConfig) -> None:
        """初始化配置访问器"""
        cls._instance = cls(config)

    @classmethod
    def get_instance(cls) -> AppConfig:
        """获取配置实例"""
        if cls._instance is None:
            raise ConfigError("Cfg_004", "Config not initialized")
        return cls._instance._config

    @classmethod
    def get(cls, key: str, default: Any = None) -> Any:
        """获取配置值"""
        return cls.get_instance().get(key, default)
```

## 6. 实现细节

### 6.1 环境变量注入

```python
import os
import re

ENV_VAR_PATTERN = re.compile(r"\$\{([^}:]+)(?::([^}]*))?\}")


def inject_env_vars(config: dict[str, Any]) -> dict[str, Any]:
    """递归注入环境变量到配置"""
    result = {}

    for key, value in config.items():
        if isinstance(value, str):
            result[key] = _replace_env_var(value)
        elif isinstance(value, dict):
            result[key] = inject_env_vars(value)
        elif isinstance(value, list):
            result[key] = [
                _replace_env_var(item) if isinstance(item, str) else item
                for item in value
            ]
        else:
            result[key] = value

    return result


def _replace_env_var(value: str) -> str:
    """替换单个字符串中的环境变量"""
    def replacer(match: re.Match) -> str:
        env_var = match.group(1)
        default = match.group(2)
        return os.environ.get(env_var, default or match.group(0))

    return ENV_VAR_PATTERN.sub(replacer, value)
```

### 6.2 配置合并策略

```python
def merge_configs(base: dict[str, Any], override: dict[str, Any]) -> dict[str, Any]:
    """深度合并配置"""
    result = base.copy()

    for key, value in override.items():
        if key in result and isinstance(result[key], dict) and isinstance(value, dict):
            result[key] = merge_configs(result[key], value)
        else:
            result[key] = value

    return result
```
