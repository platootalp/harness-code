## 1. 概述

### 1.1 模块名称

Task（任务规划）

### 1.2 职责

Task 模块是 Mozi AI Coding Agent 的核心层组件之一，负责复杂任务的规划与执行管理：
- **任务分解**：将复杂任务拆分为可执行的子任务
- **依赖分析**：分析子任务间的依赖关系，构建执行计划
- **进度跟踪**：监控任务执行状态，维护执行进度
- **失败恢复**：检测执行失败，执行回滚或重试策略
- **结果汇总**：整合多子任务执行结果，生成最终输出

### 1.3 核心能力

| 能力 | 说明 |
| --- | --- |
| 任务建模 | 支持任务的定义、状态管理、优先级排序 |
| 智能分解 | 基于 LLM 的任务分解，支持串行/并行执行计划 |
| 依赖管理 | 自动分析任务依赖，生成拓扑排序执行序列 |
| 状态跟踪 | 实时监控任务状态，支持暂停/恢复/取消操作 |
| 失败处理 | 多级重试策略、自动回滚机制、优雅降级 |
| 结果聚合 | 汇总多个子任务结果，支持部分成功场景 |
| 背景任务 | 长时间运行任务后台执行，用户可继续对话 |
| TODOList | 会话内任务清单管理，支持手动勾选和 AI 自动标注 |

### 1.4 在架构中的位置

Task 模块位于核心层（Core），在 COMPLEX 复杂度任务路由时由 Orchestrator 调用：

```
Orchestrator（COMPLEX 路由）
    │
    ▼
Planner 分解任务
    │
    ▼
Task 模块管理执行
    │
    ├──► Agent-A 执行子任务-1
    ├──► Agent-B 执行子任务-2（可并行）
    └──► Agent-C 执行子任务-3
              │
              ▼
        Task 模块汇总结果
              │
              ▼
        返回 Orchestrator
```

## 2. 核心问题与解决方案

### 2.1 任务分解质量

**问题描述**：如何将复杂任务拆分为可执行的子任务。分解质量直接影响执行效率和最终结果质量。

**挑战**：LLM 分解任务的质量和一致性难以保证。分解粒度太粗导致执行复杂，分解太细则增加管理开销。

**解决方案**：采用 LLM 驱动 + 规则约束的混合策略。TaskDecomposer 使用模型理解任务意图生成候选子任务，规则验证层检查分解完整性和可执行性，优化层合并过细粒度任务。分解结果通过 DecompositionValidator 验证有效性（完整性、原子性、独立性、可验证性）。

### 2.2 依赖管理与循环检测

**问题描述**：子任务间的依赖关系需要精确管理。循环依赖会导致任务无法完成，需要检测和避免。

**挑战**：显式依赖易于管理，但隐式依赖（共享资源、文件冲突等）难以发现。循环依赖检测算法的性能也是考虑因素。

**解决方案**：使用 DAG 图结构管理依赖关系。每个 Task 通过 `blocked_by` 和 `dependents` 字段维护依赖链。GraphManager 提供 `add_dependency()`、`remove_dependency()`、`get_ready_tasks()` 等接口。拓扑排序生成可并行执行的分层计划。

### 2.3 执行进度跟踪

**问题描述**：复杂任务执行时间长，需要实时跟踪进度。需要准确的状态管理和进度报告机制。

**挑战**：并行执行时状态同步复杂。暂停/恢复机制需要正确保存和恢复执行上下文。进度计算的准确性也难以保证。

**解决方案**：ProgressTracker 维护任务执行状态，支持暂停/恢复操作。使用 asyncio.Event 实现暂停协调。实时计算 progress 属性反映整体完成度。

### 2.4 失败恢复与降级

**问题描述**：任务失败后需要有效的恢复策略。不同失败类型需要不同处理方式，避免级联故障。

**挑战**：重试策略需要避免雪球效应。回滚机制需要正确清理副作用。降级策略需要平衡功能完整性和系统稳定性。

**解决方案**：RecoveryManager 实现多级恢复策略。RetryStrategy 使用指数退避重试，RollbackManager 逆序执行回滚处理器。降级时返回部分结果并记录失败项。

### 2.5 部分成功处理

**问题描述**：多子任务场景下，可能出现部分成功部分失败的情况。需要优雅处理这种状态。

**挑战**：如何定义"部分成功"的边界。失败子任务的影响范围如何界定。部分成功的结果如何有效利用。

**解决方案**：TaskResult 支持 subtask_results 列表记录每个子任务结果。ResultAggregator 整合结果时保留失败信息，允许调用方决定如何处理部分成功情况。

from datetime import datetime
from enum import Enum
from typing import Any
from uuid import UUID, uuid4


class TaskStatus(Enum):
    """任务状态枚举"""
    PENDING = "pending"           # 等待分解
    DECOMPOSING = "decomposing"   # 分解中
    PLANNED = "planned"          # 已分解，等待执行
    RUNNING = "running"          # 执行中
    PAUSED = "paused"            # 暂停
    COMPLETED = "completed"      # 已完成
    FAILED = "failed"           # 失败
    CANCELLED = "cancelled"      # 已取消


class TaskPriority(Enum):
    """任务优先级枚举"""
    LOW = 1
    NORMAL = 2
    HIGH = 3
    CRITICAL = 4


class TaskComplexity(Enum):
    """任务复杂度等级"""
    SIMPLE = "simple"            # 简单任务，无需分解
    MEDIUM = "medium"           # 中等任务，串行执行
    COMPLEX = "complex"         # 复杂任务，需并行执行


@dataclass
class Task:
    """统一任务模型（包含子任务层级）"""
    id: UUID = field(default_factory=uuid4)
    title: str = ""
    description: str = ""

    # 状态与优先级
    status: TaskStatus = TaskStatus.PENDING
    priority: TaskPriority = TaskPriority.NORMAL

    # 层级关系（通过 parent_id 建立树结构）
    parent_id: UUID | None = None

    # 图结构（通过 blockedBy 建立 DAG）

    dependents: list[UUID] = field(default_factory=list)   # 依赖自己的任务

    # 执行控制
    assigned_agent: str | None = None
    retry_count: int = 0
    max_retries: int = 3

    # 结果
    result: Any = None
    error: str | None = None
    evidence: Evidence | None = None

    # 元数据
    metadata: dict[str, Any] = field(default_factory=dict)


@dataclass
class TaskResult:
    """任务执行结果"""
    success: bool = False
    output: Any = None
    error: str | None = None
    child_results: list[TaskResult] = field(default_factory=list)  # 子任务结果
    execution_time_ms: int = 0
    metadata: dict[str, Any] = field(default_factory=dict)


class BackgroundTaskStatus(Enum):
    """背景任务状态枚举"""
    PENDING = "pending"      # 等待执行
    RUNNING = "running"     # 执行中

class BackgroundTask:

```
                        ┌─────────────────────────────────────────┐
                        │                 PENDING                 │
                        │            等待执行（初始状态）           │
                        └───────────────────┬─────────────────────┘
                                            │
                            ┌───────────────┴───────────────┐
                            │                               │
                            ▼                               ▼
              ┌─────────────────────────┐       ┌─────────────────────────┐
              │        IN_PROGRESS       │       │          FAILED         │
              │           执行中           │       │          失败           │
              └─────────────┬───────────┘       └─────────────────────────┘
                            │
            ┌───────────────┼───────────────┐
            │               │               │
            ▼               ▼               ▼
    ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
    │   COMPLETED   │ │    PAUSED    │ │   BLOCKED    │
    │    已完成      │ │    暂停       │ │   等待依赖    │
    └──────────────┘ └──────────────┘ └──────────────┘
                                               │
                                               ▼
                                      ┌──────────────┐
                                      │   CANCELLED  │
                                      │    已取消     │
                                      └──────────────┘
```

- `blockedBy` 非空时自动进入 BLOCKED 状态
- 依赖全部完成时自动转为 IN_PROGRESS
- PAUSED 可恢复，BLOCKED 依赖完成后自动解锁

class TaskManager(ABC):
    """任务管理器抽象接口"""

    @abstractmethod
    async def create_task(
        self,
        title: str,
        description: str,
        parent_id: UUID | None = None,
        blocked_by: list[UUID] = [],
        priority: TaskPriority = TaskPriority.NORMAL,

        """创建任务（支持层级和依赖）"""

    @abstractmethod
    async def decompose_task(
        self,
        task_id: UUID,
        context: dict[str, Any],
    ) -> list[Task]:
        """分解任务为子任务列表"""

    @abstractmethod
    async def execute_task(
        self,
        task_id: UUID,
        agents: dict[str, Agent],
    ) -> TaskResult:
        """执行任务"""

    @abstractmethod
    async def get_task_status(
        self,
        task_id: UUID,
    ) -> TaskSnapshot:
        """获取任务状态"""

    @abstractmethod
    async def pause_task(self, task_id: UUID) -> None:
        """暂停任务"""

    @abstractmethod
    async def resume_task(self, task_id: UUID) -> None:
        """恢复任务"""

    @abstractmethod
    async def cancel_task(self, task_id: UUID) -> None:
        """取消任务"""

    @abstractmethod
    async def add_dependency(self, task_id: UUID, blocked_by: UUID) -> None:
        """添加依赖关系"""

    @abstractmethod
    async def get_ready_tasks(self) -> list[Task]:
        """获取所有可执行的任务（依赖已满足）"""

    """任务分解器"""

    async def decompose(
        self,
        task: Task,
        context: dict[str, Any],
    ) -> list[SubTask]:
        """分解任务为子任务"""
        # 1. 构建分解 prompt
        prompt = self._build_decompose_prompt(task, context)

        response = await self._model.invoke(
            messages=[{"role": "user", "content": prompt}]

        subtasks = self._parse_subtasks(response.content)

        # 4. 验证和优化
        subtasks = self._validate_and_optimize(subtasks)

        # 5. 设置执行顺序
        subtasks = self._assign_execution_order(subtasks)

        return subtasks

### 6.2 失败恢复器

```python
class RecoveryManager:
    """失败恢复管理器"""

    async def handle_task_failure(
        self,
        task: Task,
        error: Exception,
        tracker: ProgressTracker,
    ) -> RecoveryAction:
        """处理任务失败"""
        current_retries = task.retry_count

        # 判断是否可重试
        if self._retry_strategy.should_retry(current_retries, error):
            delay = self._retry_strategy.calculate_delay(current_retries + 1)
            return RecoveryAction(
                action=RecoveryActionType.RETRY,
                delay_seconds=delay,
                message=f"Retrying in {delay}s (attempt {current_retries + 1})",
            )

        # 判断是否需要回滚
        if self._is_critical_task(task):
            return RecoveryAction(
                action=RecoveryActionType.ROLLBACK,
                message="Critical task failed, initiating rollback",
            )

        # 降级处理
        return RecoveryAction(
            action=RecoveryActionType.DEGRADE,
            message="Task failed, continuing with partial results",
        )
```

### 6.3 任务分解有效性验证

任务分解质量直接影响执行效率和最终结果。分解有效性通过以下四个维度评估：

#### 6.3.1 有效性维度

| 维度 | 判断标准 | 实现方式 |
| --- | --- | --- |
| **完整性** | 所有子任务覆盖原目标 | 集合覆盖检查：child tasks' goals ⊇ original goal |
| **原子性** | 子任务不可再分 | 粒度阈值：执行时间 < N分钟，或单一工具调用 |
| **独立性** | 无隐式依赖 | 共享资源检测：文件、环境变量、状态 |
| **可验证性** | 有明确的完成标准 | 每个 task 有 expected_output 描述 |

#### 6.3.2 验证流程

```python
@dataclass
class DecompositionValidation:
    """分解验证结果"""
    valid: bool
    complete: bool = True      # 完整性
    atomic: bool = True        # 原子性
    independent: bool = True   # 独立性
    verifiable: bool = True   # 可验证性
    issues: list[str] = field(default_factory=list)


class DecompositionValidator:
    """分解验证器"""

    MAX_STEPS_PER_TASK = 5  # 原子性阈值

    async def validate(
        self,
        original: str,
        child_tasks: list[dict],
    ) -> DecompositionValidation:
        """验证分解有效性"""
        issues = []

        # 1. 完整性检查：LLM 判断是否覆盖所有目标
        complete = await self._check_coverage(original, child_tasks)
        if not complete:
            issues.append("子任务未完全覆盖原始目标")

        # 2. 原子性检查：子任务步骤是否过多
        atomic = all(
            len(t.get("steps", [])) <= self.MAX_STEPS_PER_TASK
            for t in child_tasks
        )
        if not atomic:
            issues.append("部分子任务粒度过粗，需要进一步分解")

        # 3. 独立性检查：检测共享资源依赖
        dependencies = self._detect_shared_resources(child_tasks)
        independent = len(dependencies) == 0
        if not independent:
            issues.append(f"检测到共享资源冲突: {dependencies}")

        # 4. 可验证性检查：每个子任务是否有明确完成标准
        verifiable = all("expected_output" in t for t in child_tasks)
        if not verifiable:
            issues.append("部分子任务缺少 expected_output 定义")

        return DecompositionValidation(
            valid=complete and atomic and independent and verifiable,
            complete=complete,
            atomic=atomic,
            independent=independent,
            verifiable=verifiable,
            issues=issues,
        )

    async def _check_coverage(
        self,
        original: str,
        child_tasks: list[dict],
    ) -> bool:
        """检查子任务是否覆盖原始目标"""
        prompt = f"""判断以下分解是否完整覆盖了原始任务目标。

原始任务：{original}

子任务列表：
{chr(10).join([f"- {t['title']}: {t['description']}" for t in child_tasks])}

请判断：子任务是否覆盖了原始目标的所有方面？回答 YES 或 NO。"""
        response = await self._model.invoke([{"role": "user", "content": prompt}])
        return "YES" in response.content.upper()

    def _detect_shared_resources(self, child_tasks: list[dict]) -> list[str]:
        """检测共享资源依赖"""
        resource_map: dict[str, list[str]] = {}
        conflicts = []

        for task in child_tasks:
            resources = task.get("resources", [])
            for resource in resources:
                if resource not in resource_map:
                    resource_map[resource] = []
                resource_map[resource].append(task["id"])

        for resource, task_ids in resource_map.items():
            if len(task_ids) > 1:
                conflicts.append(f"{resource} 被多个任务共享: {task_ids}")

        return conflicts
```

#### 6.3.3 验证失败处理

```python
async def decompose_with_validation(
    self,
    task: Task,
    context: dict[str, Any],
) -> list[Task]:
    """带验证的分解流程"""
    child_tasks = await self._decompose(task, context)

    # 验证分解质量
    validation = await self._validator.validate(task.description, child_tasks)

    if validation.valid:
        return child_tasks

    # 完整性失败：重新分解
    if not validation.complete:
        enhanced_context = {
            **context,
            "constraint": "必须确保所有子任务覆盖原始目标的每个方面",
        }
        child_tasks = await self._decompose(task, enhanced_context)

    # 原子性失败：合并或拆分
    if not validation.atomic:
        child_tasks = self._rebalance_granularity(child_tasks)

    # 独立性失败：调整执行顺序或合并
    if not validation.independent:
        child_tasks = self._resolve_dependencies(child_tasks)

    return child_tasks
```

### 6.4 背景任务（BackgroundTaskManager）

#### 6.4.1 设计目标

长时间运行任务在后台执行，用户可以继续对话不受阻塞。

#### 6.4.2 执行流程

```
用户发起长时间任务
    │
    ├──► Task 标记 is_background=True
    │
    ▼
BackgroundTaskManager.submit(task)
    │
    ├──► 创建 BackgroundTask 记录
    ├──► 立即返回 task_id 给用户
    └──► 任务异步执行
              │
              ├──► 定期更新 progress_percent
              ├──► 完成后自动标记关联 TodoItem
              └──► 用户可随时查询进度
```

#### 6.4.3 状态机

```
PENDING ──► RUNNING ──► COMPLETED
              │
              ├──► PAUSED ──► RESUMED ──► RUNNING
              │
              └──► FAILED
```

#### 6.4.4 实现

```python
class BackgroundTaskManager:
    """背景任务管理器"""

    def __init__(
        self,
        todo_list_manager: TodoListManager,
        progress_report_interval: int = 10,  # 每 10% 上报一次
    ) -> None:
        self._todo_manager = todo_list_manager
        self._progress_interval = progress_report_interval
        self._tasks: dict[UUID, BackgroundTask] = {}

    async def submit(self, task: Task) -> UUID:
        """提交后台任务，立即返回"""
        bg_task = BackgroundTask(
            id=uuid4(),
            task_id=task.id,
            status=BackgroundTaskStatus.PENDING,
        )
        self._tasks[bg_task.id] = bg_task

        # 异步执行（不阻塞）
        asyncio.create_task(self._execute_background(bg_task, task))

        return bg_task.id

    async def _execute_background(
        self,
        bg_task: BackgroundTask,
        task: Task,
    ) -> None:
        """后台执行任务"""
        bg_task.status = BackgroundTaskStatus.RUNNING

        try:
            # 执行任务...
            for progress in self._execute_with_progress(task):
                bg_task.progress_percent = progress
                bg_task.last_progress_at = datetime.now()

                # 上报到 TODOList
                if task.id:
                    await self._todo_manager.update_progress(
                        task.id, progress
                    )

            bg_task.status = BackgroundTaskStatus.COMPLETED

            # 自动完成关联的 TODO
            await self._complete_related_todo(task)

        except Exception as e:
            bg_task.status = BackgroundTaskStatus.FAILED
            bg_task.error = str(e)

    async def get_status(self, task_id: UUID) -> BackgroundTaskStatus:
        """查询状态"""
        return self._tasks[task_id].status

    async def get_progress(self, task_id: UUID) -> int:
        """查询进度"""
        return self._tasks[task_id].progress_percent
```

### 6.5 TODO 清单（TodoListManager）

#### 6.5.1 设计目标

管理会话内任务清单，支持手动勾选和 AI 自动标注。

#### 6.5.2 核心能力

| 能力 | 说明 |
| --- | --- |
| 手动添加 | 用户或 AI 添加 TODO 项 |
| 手动勾选 | 用户手动标记完成 |
| AI 自动标注 | Task 执行完成时自动标记对应 TODO |
| 进度关联 | TODO 可关联 Task ID，显示执行进度 |
| 状态筛选 | 支持按完成状态筛选列表 |

#### 6.5.3 实现

```python
class TodoListManager:
    """TODO 清单管理器"""

    def __init__(self, storage: "TodoStorage") -> None:
        self._storage = storage

    async def add_todo(
        self,
        session_id: str,
        title: str,
        task_id: UUID | None = None,
    ) -> TodoItem:
        """添加 TODO 项"""
        todo = TodoItem(
            id=uuid4(),
            session_id=session_id,
            title=title,
            task_id=task_id,
        )
        await self._storage.save_todo(todo)
        return todo

    async def complete_todo(self, todo_id: UUID) -> None:
        """标记 TODO 完成"""
        todo = await self._storage.load_todo(todo_id)
        todo.completed = True
        todo.completed_at = datetime.now()
        await self._storage.save_todo(todo)

    async def update_progress(
        self,
        task_id: UUID,
        progress_percent: int,
    ) -> None:
        """更新关联 Task 的进度"""
        todos = await self._storage.list_todos_by_task(task_id)
        for todo in todos:
            todo.metadata["progress_percent"] = progress_percent
            await self._storage.save_todo(todo)

    async def _complete_related_todo(self, task: Task) -> None:
        """Task 完成时自动标记关联的 TODO"""
        todos = await self._storage.list_todos_by_task(task.id)
        for todo in todos:
            await self.complete_todo(todo.id)
```

#### 6.5.4 与 Task 的关联

| 场景 | 触发条件 | 行为 |
| --- | --- | --- |
| Task 开始执行 | `execute_task()` 被调用 | TODO 显示进行中状态 |
| Task 进度更新 | `progress_percent` 变化 | TODO 显示进度百分比 |
| Task 完成 | `execute_task()` 返回成功 | TODO 自动标记完成 |
| Task 失败 | `execute_task()` 抛出异常 | TODO 标记失败（可选） |
