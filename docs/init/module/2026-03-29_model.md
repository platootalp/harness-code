## 1. 概述

### 1.1 模块名称

Model（模型适配模块）

### 1.2 职责

Model 模块是 Mozi AI Coding Agent 的核心能力层之一，负责：
- 提供统一的大语言模型调用接口
- 支持多模型适配（Anthropic/OpenAI）
- 管理 Prompt 模板与变量替换
- 处理模型响应的结构化解析

> **注意**：模型选择由 Orchestrator 在路由阶段根据复杂度选择 Agent 时一并决定，Agent 内部绑定特定模型。Model 模块不负责模型选择，只负责执行模型调用。

### 1.3 核心能力

| 能力 | 说明 |
| ---- | ---- |
| 多模型适配 | 支持 Anthropic Claude 系列、OpenAI GPT 系列 |
| 统一接口 | ModelAdapter 抽象接口，统一调用方式 |
| Prompt 模板 | 模板管理、变量替换、格式化 |
| 响应解析 | 结构化解析模型输出（文本/工具调用） |
| 重试机制 | 指数退避重试、熔断保护 |
| 密钥管理 | 安全访问模型 API 密钥 |

## 2. 核心问题与解决方案

### 2.1 多模型支持与统一接口抽象

**问题描述**：不同模型有不同 API 和响应格式，如何在不修改业务代码的情况下切换模型。不同模型的接口差异给统一抽象带来挑战。

**挑战**：需要为不同模型提供统一的调用接口，同时保留各模型的特殊能力。

**解决方案**：采用适配器模式（Adapter Pattern），定义 ModelAdapter 抽象基类，统一调用方式。通过 ModelRegistry 注册表管理可用模型，动态选择对应的适配器。

### 2.2 API 稳定性与模型切换

**问题描述**：模型 API 可能变化导致调用失败，需要优雅处理。同时需要支持模型热切换。

**挑战**：外部 API 的不稳定性可能影响系统可靠性，需要设计容错机制。

**解决方案**：集成 Resilience 模块，实现指数退避重试和熔断保护。当某模型 API 不可用时，可快速切换到备用模型。

### 2.3 密钥安全与配置管理

**问题描述**：API 密钥等敏感信息需要安全管理。

**挑战**：需要在安全性和易用性之间取得平衡。

**解决方案**：密钥存储在配置文件中（如 `config/model.json`），通过 Config 模块统一管理。配置文件中的密钥字段支持从环境变量读取（实现热更新），也支持直接写入。

### 2.4 Prompt 兼容性与模板管理

**问题描述**：不同模型对 Prompt 格式要求不同，需要适配。模板需要支持变量替换和动态渲染。

**挑战**：模板需要足够灵活以适配不同模型，同时保持可维护性。

**解决方案**：实现 PromptTemplateManager，使用简单的 `{{variable}}` 占位符语法实现变量替换，不引入额外依赖。提供内置模板变量抽象层，支持模板版本管理和验证。

## 3. 数据模型与状态机

### 3.1 核心类型定义

```python
class ModelProvider(Enum):
    """模型提供商枚举"""
    ANTHROPIC = "anthropic"
    OPENAI = "openai"


class MessageRole(Enum):
    """消息角色枚举"""
    SYSTEM = "system"
    USER = "user"
    ASSISTANT = "assistant"
    TOOL = "tool"


@dataclass
class Message:
    """对话消息"""
    role: MessageRole
    content: str
    name: str | None = None
    tool_calls: list[ToolCall] | None = None
    tool_call_id: str | None = None


@dataclass
class ToolCall:
    """工具调用"""
    id: str
    name: str
    arguments: dict[str, Any]


@dataclass
class ModelRequest:
    """模型调用请求"""
    model: str
    messages: list[Message]
    system_prompt: str | None = None
    temperature: float = 1.0
    max_tokens: int | None = None
    top_p: float | None = None
    stop_sequences: list[str] | None = None
    tools: list[dict[str, Any]] | None = None
    stream: bool = False
    metadata: dict[str, Any] = field(default_factory=dict)


@dataclass
class ModelResponse:
    """模型调用响应"""
    content: str
    model: str
    stop_reason: str | None = None
    tool_calls: list[ToolCall] | None = None
    usage: ModelUsage | None = None
    metadata: dict[str, Any] = field(default_factory=dict)


@dataclass
class ModelUsage:
    """模型使用量"""
    input_tokens: int = 0
    output_tokens: int = 0
    total_tokens: int = 0


@dataclass
class ModelInfo:
    """模型信息"""
    name: str
    provider: ModelProvider
    display_name: str
    context_window: int
    tier: str  # "fast" | "balanced" | "powerful"
    supports_tools: bool = True
    supports_vision: bool = False
```

## 5. 接口、交互与流程

### 5.1 核心接口定义

```python
class ModelAdapter(ABC):
    """模型适配器抽象基类"""

    @property
    @abstractmethod
    def provider(self) -> ModelProvider:
        """返回模型提供商"""
        raise NotImplementedError

    @property
    @abstractmethod
    def supported_models(self) -> list[ModelInfo]:
        """返回支持的模型列表"""
        raise NotImplementedError

    @abstractmethod
    async def invoke(self, request: ModelRequest) -> ModelResponse:
        """调用模型"""
        raise NotImplementedError

    @abstractmethod
    async def invoke_stream(
        self,
        request: ModelRequest,
    ) -> AsyncIterator[ModelStreamEvent]:
        """流式调用模型"""
        raise NotImplementedError

    @abstractmethod
    def validate_request(self, request: ModelRequest) -> None:
        """验证请求参数"""
        raise NotImplementedError

    @abstractmethod
    def parse_response(self, raw_response: Any) -> ModelResponse:
        """解析原始响应"""
        raise NotImplementedError


class ModelRegistry:
    """模型注册表"""

    def register_adapter(self, adapter: ModelAdapter) -> None:
        """注册模型适配器"""
        ...

    def get_adapter(self, provider: ModelProvider) -> ModelAdapter | None:
        """获取指定提供商的适配器"""
        ...

    def get_adapter_by_model(self, model_name: str) -> ModelAdapter | None:
        """根据模型名获取适配器"""
        ...
```

### 5.2 适配器关键差异

| 特性 | AnthropicAdapter | OpenAIAdapter |
| ---- | ---------------- | ------------- |
| API 端点 | `/v1/messages` | `/v1/chat/completions` |
| 认证方式 | `x-api-key` header | `Authorization: Bearer` |
| 工具调用格式 | `tool_use` content block | `tool_calls` in message |
| system_prompt | `system` 字段 | `messages[0].role=system` |
| 响应内容块 | `content[].type=text/tool_use` | `message.tool_calls[]` |
| stop_reason | `stop_reason` | `finish_reason` |
| usage 字段 | `input_tokens/output_tokens` | `prompt_tokens/completion_tokens` |

## 6. 边界与契约

### 6.1 错误码定义

> **说明**：Model 模块的错误处理遵循统一异常体系。

| 错误码 | 错误类型 | 说明 |
| ------ | -------- | ---- |
| `MODEL_001` | ModelInvocationError | 模型调用失败 |
| `MODEL_002` | ModelNotFoundError | 模型不存在 |
| `MODEL_003` | InvalidRequestError | 无效请求参数 |
| `MODEL_004` | ResponseParseError | 响应解析失败 |
| `MODEL_005` | RateLimitError | 请求限流 |
| `MODEL_006` | AuthenticationError | 认证失败 |
| `MODEL_007` | CircuitBreakerOpenError | 熔断器开启 |

### 6.2 API 契约

#### 6.2.1 ModelAdapter.invoke()

**请求**：
```python
async def invoke(self, request: ModelRequest) -> ModelResponse
```

**响应**：
- `ModelResponse`: 模型响应对象

**错误**：
- `MODEL_001`: 当模型调用失败时抛出
- `MODEL_003`: 当请求参数无效时抛出
- `MODEL_004`: 当响应解析失败时抛出

### 6.3 约束与限制

| 约束 | 限制值 | 说明 |
| ---- | ------ | ---- |
| temperature | 0.0 - 2.0 | 采样温度 |
| max_tokens | > 0 | 最大生成 token 数 |
| top_p | 0.0 - 1.0 | 核采样概率 |
| 请求超时 | 60 秒 | 可通过配置调整 |
| 最大重试次数 | 3 | 可通过配置调整 |

### 7.3 重试策略

```python
class RetryStrategy:
    """重试策略"""

    def __init__(
        self,
        max_retries: int = 3,
        base_delay: float = 1.0,
        max_delay: float = 60.0,
        exponential_base: float = 2.0,
    ) -> None:
        self._max_retries = max_retries
        self._base_delay = base_delay
        self._max_delay = max_delay
        self._exponential_base = exponential_base

    def should_retry(self, attempt: int, error: Exception) -> bool:
        """判断是否应该重试"""
        if attempt >= self._max_retries:
            return False
        # 判断错误类型是否可重试
        return isinstance(error, (RateLimitError, TemporaryError))

    def calculate_delay(self, attempt: int) -> float:
        """计算退避延迟"""
        delay = self._base_delay * (self._exponential_base ** attempt)
        return min(delay, self._max_delay)
```

### 7.4 熔断保护

```python
class CircuitBreaker:
    """熔断保护器"""

    def __init__(
        self,
        failure_threshold: int = 5,
        recovery_timeout: float = 60.0,
        half_open_max_calls: int = 3,
    ) -> None:
        self._failure_threshold = failure_threshold
        self._recovery_timeout = recovery_timeout
        self._half_open_max_calls = half_open_max_calls
        self._failure_count = 0
        self._last_failure_time: float | None = None
        self._state = CircuitState.CLOSED

    async def call(self, func: Callable[..., T]) -> T:
        """执行函数，带熔断保护"""
        if self._state == CircuitState.OPEN:
            if self._should_attempt_reset():
                self._state = CircuitState.HALF_OPEN
            else:
                raise CircuitBreakerOpenError()

        try:
            result = await func()
            self._on_success()
            return result
        except Exception as e:
            self._on_failure()
            raise
```

## 8. 配置

### 8.1 配置文件

密钥和配置通过 `config/model.json` 管理：

```json
{
  "model": {
    "anthropic": {
      "api_key": "${ANTHROPIC_API_KEY}",
      "api_key_fallback": "sk-..."
    },
    "openai": {
      "api_key": "${OPENAI_API_KEY}",
      "api_key_fallback": "sk-...",
      "organization": "${OPENAI_ORG}"
    },
    "defaults": {
      "timeout": 60,
      "max_retries": 3,
      "base_url": null
    }
  }
}
```

### 8.2 环境变量覆盖

| 变量名 | 说明 | 默认值 | 必填 |
| ------ | ---- | ------ | ---- |
| `ANTHROPIC_API_KEY` | Anthropic API 密钥 | - | 是 |
| `OPENAI_API_KEY` | OpenAI API 密钥 | - | 是 |
| `OPENAI_ORG` | OpenAI 组织 ID | - | 否 |
| `MODEL_BASE_URL` | 自定义 API 端点 | - | 否 |
| `MODEL_TIMEOUT` | 请求超时秒数 | 60 | 否 |
| `MODEL_MAX_RETRIES` | 最大重试次数 | 3 | 否 |

### 8.3 配置验证规则

| 参数 | 有效范围 | 说明 |
| ---- | -------- | ---- |
| `temperature` | 0.0 - 2.0 | 采样温度 |
| `max_tokens` | > 0 | 最大生成 token 数 |
| `top_p` | 0.0 - 1.0 | 核采样概率 |
