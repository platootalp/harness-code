## 1. 概述

### 1.1 模块名称

Security（安全模块）

### 1.2 职责

Security 模块是 Mozi AI Coding Agent 的横切面安全组件，负责：
- 管理密钥和凭证的安全访问
- 检测和阻止硬编码密钥泄露
- 提供敏感信息的安全存储和注入机制

> **重要变更**：工具执行安全相关能力（白名单、沙箱、危险函数检测）已迁移至 Tools 模块。本模块现专注于密钥管理等横切面安全能力。

### 1.3 核心能力

| 能力 | 说明 |
| ---- | ---- |
| 密钥管理 | 环境变量注入，禁止硬编码 |
| 硬编码检测 | AST 静态分析扫描硬编码密钥 |
| 敏感信息存储 | 密钥的安全存储和按需注入 |

---

## 2. 核心问题与解决方案

### 2.1 敏感信息泄露防护

**问题描述**：密钥、密码等敏感信息可能被意外暴露在日志、代码或产物中。

**挑战**：需要在安全性和开发便利性之间取得平衡。

**解决方案**：实现 SecretManager 通过环境变量注入密钥，禁止硬编码。提供 HARDCODED_SECRET_PATTERNS 进行硬编码检测，扫描禁止硬编码密钥。

## 3. 数据模型

### 3.1 密钥配置

```python
@dataclass
class SecretConfig:
    """密钥配置"""
    name: str                          # 密钥名称
    source: SecretSource                # 密钥来源
    required: bool = False             # 是否必需
    description: str = ""              # 密钥描述


class SecretSource(Enum):
    """密钥来源枚举"""
    ENVIRONMENT = "environment"        # 环境变量
    VAULT = "vault"                    # 密钥管理器
    FILE = "file"                      # 密钥文件


@dataclass
class Secret:
    """密钥对象"""
    name: str
    value: str
    source: SecretSource
    masked: bool = True               # 是否脱敏显示
```

### 3.2 硬编码检测模式

```python
HARDCODED_SECRET_PATTERNS: list[tuple[str, str, str]] = [
    # (pattern_name, regex, severity)
    ("AWS Access Key", r'AKIA[0-9A-Z]{16}', "HIGH"),
    ("AWS Secret Key", r'[A-Za-z0-9/+=]{40}', "HIGH"),
    ("GitHub Token", r'ghp_[A-Za-z0-9]{36}', "HIGH"),
    ("OpenAI API Key", r'sk-[A-Za-z0-9]{48}', "HIGH"),
    ("Generic API Key", r'[Aa]pi[keyK][_-]?)?[A-Za-z0-9]{20,}', "MEDIUM"),
    ("Private Key", r'-----BEGIN (RSA |EC |DSA )?PRIVATE KEY-----', "HIGH"),
    ("Password in URL", r'://[^:]+:[^@]+@', "MEDIUM"),
]
```

## 6. 实现细节

### 6.1 密钥注入流程

```python
class SecretManager:
    """密钥管理器"""

    async def inject_to_environment(
        self,
        names: list[str] | None = None
    ) -> dict[str, str]:
        """将密钥注入到环境变量"""
        if names is None:
            names = list(self._secrets.keys())

        env_vars = {}
        for name in names:
            secret = await self.get_secret(name)
            if secret:
                env_vars[name] = secret

        # 更新当前进程环境变量
        os.environ.update(env_vars)
        return env_vars
```

### 6.2 硬编码检测扫描器

class HardcodedSecretScanner:
    """硬编码密钥扫描器"""

    def scan_file(self, file_path: Path) -> list[SecretViolation]:
        """扫描单个文件"""
        violations = []
        content = file_path.read_text()

        for pattern_name, regex, severity in HARDCODED_SECRET_PATTERNS:
            matches = re.finditer(regex, content)
            for match in matches:
                violations.append(SecretViolation(
                    file_path=str(file_path),
                    pattern_name=pattern_name,
                    line_number=self._get_line_number(content, match.start()),
                    severity=severity,

| ------ | ---- | -------- |
