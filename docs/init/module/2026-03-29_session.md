## 1. 模块概述

### 1.1 模块名称

Session（会话管理）

### 1.2 职责

Session 模块是 Mozi 系统的核心层组件，负责管理用户与 Agent 之间的会话生命周期，
维护会话元数据，控制上下文窗口，以及提供会话持久化能力。

### 1.3 核心能力

| 能力                   | 说明                                                     |
| ---------------------- | -------------------------------------------------------- |
| 会话生命周期管理       | 创建、获取、更新、删除会话                               |
| 元数据存储             | 会话状态、创建时间、最后活跃时间、用户偏好               |
| 消息存储               | 消息追加、获取、列表管理                                 |
| 会话持久化             | 支持文件存储、跨会话恢复                                 |
| 流式输出持久化         | 流式输出过程中渐进式保存，崩溃后可恢复                   |

### 1.4 核心问题

| 问题 | 说明 |
| ---- | ---- |
| 会话状态管理 | 如何管理会话的创建、更新、删除生命周期 |
| 会话恢复 | 应用重启后如何恢复之前的会话状态 |
| 多会话并发 | 支持多用户多会话并发，彼此隔离 |
| 消息存储效率 | 如何高效存储和检索大量消息 |

### 1.5 难点

| 难点 | 说明 |
| ---- | ---- |
| 会话数据一致性 | 高并发下的会话数据一致性问题 |
| 历史消息清理 | 何时清理、清理哪些历史消息 |
| 存储性能 | 大量会话和消息的存储性能 |

### 1.6 解决方案

| 方案 | 说明 |
| ---- | ---- |
| SessionManager | 会话生命周期管理，CRUD 操作 |
| SQLite 持久化 | SQLiteSessionStorage 支持多进程并发 |
| WAL 模式 | 更好的并发读写性能 |
| 大结果文件存储 | 超过阈值的工具调用结果存文件 |

## 3. 会话模型

### 3.1 核心模型定义

```python
from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
from typing import Optional
from uuid import UUID, uuid4


class SessionStatus(Enum):
    """会话状态"""
    ACTIVE = "active"       # 活跃会话
    IDLE = "idle"           # 空闲会话（超过阈值未交互）
    ARCHIVED = "archived"   # 已归档会话
    EXPIRED = "expired"     # 已过期会话


class MessageRole(Enum):
    """消息角色"""
    SYSTEM = "system"        # 系统消息
    USER = "user"            # 用户消息
    ASSISTANT = "assistant" # Assistant 消息
    TOOL = "tool"            # 工具调用结果


@dataclass
class Message:
    """消息结构"""
    id: str = field(default_factory=lambda: str(uuid4()))
    session_id: str = ""
    role: MessageRole = MessageRole.USER
    content: str = ""
    timestamp: datetime = field(default_factory=datetime.now)
    tool_call_id: Optional[str] = None
    attachment_path: Optional[str] = None  # 大结果存文件
    metadata: dict = field(default_factory=dict)
    streaming_content: str = ""           # 流式输出过程中的渐进内容
    is_streaming: bool = False            # 是否正在流式输出


@dataclass
class Session:
    """会话结构"""
    id: str = field(default_factory=lambda: str(uuid4()))
    name: str = ""
    working_dir: str = ""
    status: SessionStatus = SessionStatus.ACTIVE
    metadata: dict = field(default_factory=dict)
    user_id: Optional[str] = None
    tags: list[str] = field(default_factory=list)
    created_at: datetime = field(default_factory=datetime.now)
    updated_at: datetime = field(default_factory=datetime.now)
    last_active_at: datetime = field(default_factory=datetime.now)
```

### 3.2 生命周期状态机

```
                    创建
                      │
                      ▼
    ┌──────────────────────────────────────┐
    │              ACTIVE                   │
    │  (收到消息/发送消息时更新 last_active)│
    └──────────────┬───────────────────────┘
                   │ 超过 idle_timeout 无交互
                   ▼
    ┌──────────────────────────────────────┐
    │               IDLE                   │◄────────┐
    │  (可恢复，保留完整上下文)             │         │
    └──────────────┬───────────────────────┘         │
                   │ 超过 max_lifetime               │ 用户继续交互
                   ▼                                 │
    ┌──────────────────────────────────────┐         │
    │             ARCHIVED                 │─────────┘
    │  (压缩存储，可手动恢复)
    └──────────────┬───────────────────────┘
                   │ 超过 archive_lifetime
                   ▼
    ┌──────────────────────────────────────┐
    │             EXPIRED                  │
    │  (自动清理)
    └──────────────────────────────────────┘
```

### 4.3 SQLite 存储实现

```python
import sqlite3
from pathlib import Path
from typing import Optional
import json

from .storage import SessionStorage


class SQLiteSessionStorage(SessionStorage):
    """SQLite 存储实现，支持多进程并发"""

    def __init__(
        self,
        db_path: str = "~/.mozi/sessions.db",
        tool_call_file_threshold: int = 4096,  # 4KB
        attachment_dir: str = "~/.mozi/attachments",
    ) -> None:
        self._db_path = Path(db_path).expanduser()
        self._tool_call_file_threshold = tool_call_file_threshold
        self._attachment_dir = Path(attachment_dir).expanduser()
        self._init_db()

    def _init_db(self) -> None:
        """初始化数据库和表结构"""
        self._db_path.parent.mkdir(parents=True, exist_ok=True)
        self._attachment_dir.mkdir(parents=True, exist_ok=True)

        with sqlite3.connect(self._db_path) as conn:
            # 启用 WAL 模式以支持更好的并发
            conn.execute("PRAGMA journal_mode=WAL")
            conn.execute("PRAGMA busy_timeout=5000")

            # 创建表
            conn.executescript("""
                CREATE TABLE IF NOT EXISTS sessions (
                    id TEXT PRIMARY KEY,
                    name TEXT NOT NULL DEFAULT '',
                    working_dir TEXT NOT NULL DEFAULT '',
                    status TEXT NOT NULL DEFAULT 'active',
                    metadata TEXT NOT NULL DEFAULT '{}',
                    user_id TEXT,
                    tags TEXT NOT NULL DEFAULT '[]',
                    created_at TEXT NOT NULL,
                    updated_at TEXT NOT NULL,
                    last_active_at TEXT NOT NULL
                );

                CREATE TABLE IF NOT EXISTS messages (
                    id TEXT PRIMARY KEY,
                    session_id TEXT NOT NULL,
                    role TEXT NOT NULL,
                    content TEXT NOT NULL DEFAULT '',
                    timestamp TEXT NOT NULL,
                    tool_call_id TEXT,
                    attachment_path TEXT,
                    metadata TEXT NOT NULL DEFAULT '{}',
                    streaming_content TEXT NOT NULL DEFAULT '',
                    is_streaming INTEGER NOT NULL DEFAULT 0,
                    FOREIGN KEY (session_id) REFERENCES sessions(id) ON DELETE CASCADE
                );

                CREATE INDEX IF NOT EXISTS idx_messages_session_id ON messages(session_id);
            """)

    def _serialize_session(self, session: Session) -> dict:
        """序列化 Session 对象"""
        return {
            "id": session.id,
            "name": session.name,
            "working_dir": session.working_dir,
            "status": session.status.value,
            "metadata": json.dumps(session.metadata),
            "user_id": session.user_id,
            "tags": json.dumps(session.tags),
            "created_at": session.created_at.isoformat(),
            "updated_at": session.updated_at.isoformat(),
            "last_active_at": session.last_active_at.isoformat(),
        }

    def _deserialize_session(self, row: tuple) -> Session:
        """从数据库行反序列化 Session 对象"""
        return Session(
            id=row[0],
            name=row[1],
            working_dir=row[2],
            status=SessionStatus(row[3]),
            metadata=json.loads(row[4]),
            user_id=row[5],
            tags=json.loads(row[6]),
            created_at=datetime.fromisoformat(row[7]),
            updated_at=datetime.fromisoformat(row[8]),
            last_active_at=datetime.fromisoformat(row[9]),
        )

    def _serialize_message(self, message: Message) -> dict:
        """序列化 Message 对象，处理大结果存储"""
        attachment_path = message.attachment_path

        # 如果内容超过阈值，存文件
        if len(message.content) > self._tool_call_file_threshold:
            attachment_path = self._save_attachment(message.id, message.content)
            content = ""  # 内容存在文件中，数据库只存路径
        else:
            content = message.content

        return {
            "id": message.id,
            "session_id": message.session_id,
            "role": message.role.value,
            "content": content,
            "timestamp": message.timestamp.isoformat(),
            "tool_call_id": message.tool_call_id,
            "attachment_path": attachment_path,
            "metadata": json.dumps(message.metadata),
            "streaming_content": message.streaming_content,
            "is_streaming": int(message.is_streaming),
        }

    def _load_attachment(self, path: str) -> str:
        """从文件加载附件内容"""
        with open(path, "r", encoding="utf-8") as f:
            return f.read()

    def _save_attachment(self, message_id: str, content: str) -> str:
        """保存附件到文件"""
        path = self._attachment_dir / f"{message_id}.txt"
        with open(path, "w", encoding="utf-8") as f:
            f.write(content)
        return str(path)

    async def save_session(self, session: Session) -> None:
        """保存会话"""
        data = self._serialize_session(session)
        with sqlite3.connect(self._db_path) as conn:
            conn.execute("""
                INSERT OR REPLACE INTO sessions
                (id, name, working_dir, status, metadata, user_id, tags,
                 created_at, updated_at, last_active_at)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            """, (
                data["id"], data["name"], data["working_dir"], data["status"],
                data["metadata"], data["user_id"], data["tags"],
                data["created_at"], data["updated_at"], data["last_active_at"],
            ))

    async def load_session(self, session_id: str) -> Optional[Session]:
        """加载会话"""
        with sqlite3.connect(self._db_path) as conn:
            cursor = conn.execute(
                "SELECT * FROM sessions WHERE id = ?", (session_id,)
            )
            row = cursor.fetchone()
            if row is None:
                return None
            return self._deserialize_session(row)

    async def delete_session(self, session_id: str) -> bool:
        """删除会话（级联删除消息）"""
        with sqlite3.connect(self._db_path) as conn:
            cursor = conn.execute(
                "DELETE FROM sessions WHERE id = ?", (session_id,)
            )
            return cursor.rowcount > 0

    async def list_sessions(
        self,
        status: Optional[SessionStatus] = None,
        limit: int = 100,
    ) -> list[Session]:
        """列出会话"""
        with sqlite3.connect(self._db_path) as conn:
            if status:
                cursor = conn.execute("""
                    SELECT * FROM sessions
                    WHERE status = ?
                    ORDER BY last_active_at DESC
                    LIMIT ?
                """, (status.value, limit))
            else:
                cursor = conn.execute("""
                    SELECT * FROM sessions
                    ORDER BY last_active_at DESC
                    LIMIT ?
                """, (limit,))

            return [self._deserialize_session(row) for row in cursor]

    async def save_message(self, session_id: str, message: Message) -> None:
        """保存消息"""
        data = self._serialize_message(message)
        data["session_id"] = session_id
        with sqlite3.connect(self._db_path) as conn:
            conn.execute("""
                INSERT INTO messages
                (id, session_id, role, content, timestamp, tool_call_id,
                 attachment_path, metadata, streaming_content, is_streaming)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            """, (
                data["id"], data["session_id"], data["role"], data["content"],
                data["timestamp"], data["tool_call_id"], data["attachment_path"],
                data["metadata"], data["streaming_content"], data["is_streaming"],
            ))

    async def load_messages(self, session_id: str) -> list[Message]:
        """加载会话的所有消息"""
        with sqlite3.connect(self._db_path) as conn:
            cursor = conn.execute("""
                SELECT * FROM messages
                WHERE session_id = ?
                ORDER BY timestamp ASC
            """, (session_id,))

            messages = []
            for row in cursor:
                msg = self._deserialize_message(row)
                # 如果有附件路径，从文件加载内容
                if msg.attachment_path and not msg.content:
                    msg.content = self._load_attachment(msg.attachment_path)
                messages.append(msg)
            return messages

    def _deserialize_message(self, row: tuple) -> Message:
        """从数据库行反序列化 Message 对象"""
        return Message(
            id=row[0],
            session_id=row[1],
            role=MessageRole(row[2]),
            content=row[3],
            timestamp=datetime.fromisoformat(row[4]),
            tool_call_id=row[5],
            attachment_path=row[6],
            metadata=json.loads(row[7]),
            streaming_content=row[8],
            is_streaming=bool(row[9]),
        )

    async def update_message(self, message: Message) -> None:
        """更新消息"""
        data = self._serialize_message(message)
        with sqlite3.connect(self._db_path) as conn:
            conn.execute("""
                UPDATE messages SET
                    role = ?, content = ?, timestamp = ?, tool_call_id = ?,
                    attachment_path = ?, metadata = ?, streaming_content = ?,
                    is_streaming = ?
                WHERE id = ?
            """, (
                data["role"], data["content"], data["timestamp"],
                data["tool_call_id"], data["attachment_path"], data["metadata"],
                data["streaming_content"], data["is_streaming"], data["id"],
            ))

    async def delete_message(self, message_id: str) -> bool:
        """删除消息"""
        with sqlite3.connect(self._db_path) as conn:
            cursor = conn.execute(
                "DELETE FROM messages WHERE id = ?", (message_id,)
            )
            return cursor.rowcount > 0
```

### 4.4 并发与保存策略

SQLite 采用 **WAL (Write-Ahead Logging)** 模式，支持多进程并发读写：

| 特性 | 说明 |
| ---- | ---- |
| WAL 模式 | 写操作不阻塞读，读操作不阻塞写 |
| 实时保存 | 每条消息后立即写入数据库 |
| 崩溃恢复 | WAL 日志确保已提交事务不丢失 |
| 消息级持久化 | Message 独立持久化，不依赖 Session |

默认采用**实时保存**策略：每条消息后立即保存（`auto_save_message_count=1`），确保崩溃后可恢复。

### 4.5 崩溃恢复流程

```
进程崩溃
    │
    ▼
用户重新启动 Mozi
    │
    ▼
用户执行: resume <session-id>
    │
    ▼
系统加载 Session（从最后一条已保存消息）
    │
    ▼
Orchestrator 重新理解用户意图
（工作循环从头开始决策，不恢复运行时状态）
```

#### 4.4.1 resume 命令行为

```
resume <session-id>
    │
    ├──► Session 不存在 → 报错：Session not found
    │
    └──► Session 存在
            │
            ├──► 加载 session
            ├──► 获取最后一条消息
            ├──► 展示 "Resuming session <id>, last message:"
            ├──► 显示最后一条消息内容
            └──► 继续工作循环
```

#### 4.4.2 流式输出恢复

| 阶段 | streaming_content | is_streaming | content |
|------|-------------------|--------------|---------|
| 开始流式输出 | "" | True | "" |
| 流式输出中 | 渐进更新 | True | "" |
| 流式输出完成 | → content | False | 完整内容 |

崩溃恢复时：
- 如果 `is_streaming == True`，使用 `streaming_content` 作为上下文继续
- Orchestrator 重新发送 LLM 请求，带上已输出的内容作为 `continue_from` 参数

#### 4.4.3 相关模块职责

| 模块 | 职责 |
|------|------|
| Session | 消息持久化，加载恢复 |
| Orchestrator | 不保存运行时状态，恢复后从头决策 |
| Task | Task 自身负责持久化，恢复时由 Orchestrator 重新委托 |
| Memory | 按原有机制工作，不受崩溃恢复影响 |

#### 4.4.4 无需实现的功能

| 功能 | 原因 |
|------|------|
| Checkpoint 机制 | 消息立即持久化后无需 checkpoint |
| 运行时状态保存 | Orchestrator 工作循环阶段属于运行时状态，崩溃后不恢复 |
| 自动恢复 | 用户显式执行 `resume` 命令恢复 |

```python
class SessionManager(BaseSessionManager):
    """会话管理器实现"""

    def __init__(
        self,

    ) -> None:

        self._config = config

    async def create(
        self,

            working_dir=working_dir,
            metadata=metadata or {},
            user_id=user_id,
        )
        await self._storage.save_session(session)
        return session

    async def get(self, session_id: str) -> Optional[Session]:
        """获取会话"""
        session = await self._storage.load_session(session_id)
        if session:
            # 更新最后活跃时间
            session.last_active_at = datetime.now()
            await self._storage.save_session(session)
        return session

    async def update(self, session: Session) -> Session:
        """更新会话"""
        session.updated_at = datetime.now()
        await self._storage.save_session(session)
        return session

    async def delete(self, session_id: str) -> bool:
        """删除会话"""
        return await self._storage.delete_session(session_id)

    async def list(
        self,
        status: Optional[SessionStatus] = None,
        limit: int = 100,
    ) -> list[Session]:
        """列出会话"""
        return await self._storage.list_sessions(status=status, limit=limit)
```

## 6. 数据流

### 6.1 与 Orchestrator 的交互

```
Orchestrator
    │
    ├──► session_manager.create() ──► 创建新会话
    │
    ├──► session_manager.get() ──► 获取会话
    │
    ├──► session_manager.update() ──► 保存会话更新
    │
    └──► session_manager.append_message() ──► 追加消息并持久化
              │
              ▼
         SQLiteSessionStorage ──► 持久化到数据库 (WAL 模式)
```

Session 模块仅负责会话的创建、获取、更新和消息存储。
上下文构建和压缩由 Context 模块负责，详细设计见 [Context 模块设计文档](./2026-03-29_context.md#63-与-session-的交互)。
