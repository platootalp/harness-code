## 1. 概述

### 1.1 模块名称

Storage（存储层）

### 1.2 职责

Storage 模块是 Mozi 系统的基础设施层组件，负责所有持久化数据的存储和管理：
- 会话数据的持久化和恢复
- 长期记忆的向量化存储
- 产物文件（Artifact）的管理和存储
- 存储迁移和版本管理

### 1.3 核心能力

| 能力 | 说明 |
| --- | --- |
| 会话持久化 | 会话数据的创建、读取、更新、删除，支持跨会话恢复 |
| 记忆存储 | 长期记忆的向量化和持久化，支持语义检索 |
| 文件管理 | 产物文件的存储、检索、清理和空间管理 |
| 存储抽象 | 多后端存储支持（文件系统，云存储），统一接口 |
| 迁移管理 | 数据迁移、版本升级、向后兼容 |

## 2. 核心问题与解决方案

### 2.1 存储抽象与多后端支持

**问题描述**：不同类型数据需要不同存储后端。需要统一的存储接口支持多种后端实现。

**挑战**：如何设计统一的存储接口，同时保持各后端的特殊能力。

**解决方案**：定义 StorageBase 抽象基类，统一接口定义（save/load/delete/exists/list_keys/get_metadata）。子类实现具体后端（FileStorage、SQLiteStorage、S3Storage 等）。

### 2.2 数据持久化与一致性

**问题描述**：会话、记忆、产物等数据需要可靠的持久化。读写操作可能出现数据不一致或丢失。

**挑战**：在保证数据一致性的同时，提供良好的性能。原子写入的实现也是难点。

**解决方案**：采用原子写入（write-then-rename）策略确保写入一致性。FileSessionStorage 实现基于文件的会话持久化，Session 数据定期自动保存。

### 2.3 向量检索与语义记忆

**问题描述**：长期记忆需要向量检索能力支持语义相似度匹配。向量存储引擎的选择影响检索质量和性能。

**挑战**：向量存储选型（Faiss、Milvus 等）与轻量级实现的平衡。向量检索的准确性vs性能权衡。

**解决方案**：定义 VectorStore 抽象接口，支持 FileVectorStore 轻量级实现（基于余弦相似度）。支持按 session_id 和 memory_type 多维度过滤。

### 2.4 存储空间管理与清理

**问题描述**：产物文件的持续增长会消耗大量存储空间。需要有效的清理策略和空间回收机制。

**挑战**：如何设计清理策略避免误删重要数据，同时控制存储成本。

**解决方案**：实现 ArtifactManager 支持过期时间（expires_at）管理。提供 cleanup_expired() 方法删除过期产物。配置 retention_days 控制数据保留期限。

## 3. 数据模型

### 3.1 存储配置

```python
class StorageBackend(Enum):
    """存储后端类型"""
    FILE_SYSTEM = "file_system"
    SQLITE = "sqlite"
    POSTGRESQL = "postgresql"
    S3 = "s3"
    MEMORY = "memory"


@dataclass
class StorageConfig:
    """存储配置"""
    backend: StorageBackend = StorageBackend.FILE_SYSTEM
    base_path: str = "~/.mozi/storage"
    max_size_mb: int = 1024
    auto_cleanup: bool = True
    cleanup_interval_hours: int = 24
    retention_days: int = 30
```

### 3.2 会话数据模型

```python
class SessionStatus(Enum):
    """会话状态"""
    ACTIVE = "active"
    IDLE = "idle"
    ARCHIVED = "archived"
    EXPIRED = "expired"


class MessageRole(Enum):
    """消息角色"""
    SYSTEM = "system"
    USER = "user"
    ASSISTANT = "assistant"
    TOOL = "tool"


@dataclass
class Session:
    """会话结构"""
    id: str
    name: str = ""
    working_dir: str = ""
    status: SessionStatus = SessionStatus.ACTIVE
    metadata: dict[str, Any] = field(default_factory=dict)
    user_id: str | None = None
    tags: list[str] = field(default_factory=list)
    created_at: datetime = field(default_factory=datetime.now)
    updated_at: datetime = field(default_factory=datetime.now)
    last_active_at: datetime = field(default_factory=datetime.now)
```

### 3.3 记忆数据模型

```python
class MemoryType(Enum):
    """记忆类型"""
    SHORT_TERM = "short_term"    # 短期记忆 - 滑动窗口
    SEMANTIC = "semantic"        # 语义记忆 - 一般知识
    EPISODIC = "episodic"        # 情景记忆 - 过去事件
    PROCEDURAL = "procedural"     # 程序记忆 - 行为模式


@dataclass
class MemoryBlock:
    """记忆块"""
    id: str
    session_id: str
    content: str
    memory_type: MemoryType
    embedding: list[float] | None = None
    importance: float = 0.5
    status: SessionStatus = SessionStatus.ACTIVE  # ACTIVE/ARCHIVED/DELETED
    created_at: datetime = field(default_factory=datetime.now)
    accessed_at: datetime = field(default_factory=datetime.now)
    metadata: dict[str, Any] = field(default_factory=dict)
```

## 5. 接口与交互

### 5.1 存储接口

```python
class StorageBase(ABC):
    """存储抽象基类"""

    @abstractmethod
    async def save(self, key: str, data: bytes | str, metadata: dict | None = None) -> None:
        """保存数据"""

    @abstractmethod
    async def load(self, key: str) -> bytes | str | None:
        """加载数据"""

    @abstractmethod
    async def delete(self, key: str) -> bool:
        """删除数据"""

    @abstractmethod
    async def exists(self, key: str) -> bool:
        """检查键是否存在"""

    @abstractmethod
    async def list_keys(self, prefix: str | None = None, limit: int | None = None) -> list[str]:
        """列出键"""
```

### 5.2 会话存储接口

```python
class SessionStorage(ABC):
    """会话存储抽象接口"""

    @abstractmethod
    async def save(self, session: Session) -> None:
        """保存会话"""

    @abstractmethod
    async def load(self, session_id: str) -> Session | None:
        """加载会话"""

    @abstractmethod
    async def delete(self, session_id: str) -> bool:
        """删除会话"""

    @abstractmethod
    async def list(self, status: SessionStatus | None = None, user_id: str | None = None, limit: int = 100) -> list[Session]:
        """列出会话"""
```

### 5.3 向量存储接口

```python
class VectorStore(ABC):
    """向量存储抽象接口"""

    @abstractmethod
    async def upsert(self, session_id: str, blocks: list[MemoryBlock]) -> None:
        """插入或更新记忆块"""

    @abstractmethod
    async def search(
        self,
        query_embedding: list[float],
        session_id: str | None = None,
        memory_type: MemoryType | None = None,
        top_k: int = 5,
        threshold: float = 0.7,
    ) -> list[tuple[MemoryBlock, float]]:
        """搜索相似记忆"""
```

```

        │
        ├──► FileSessionStorage ──► 文件系统
```

### 6.2 记忆存储架构

```
MemoryStorageManager
        │
        ├──► VectorStore ──► 向量存储接口
        │         │
        │         ├──► FileVectorStore ──► 文件系统向量存储
        │         │
        │         └──► PGVectorStore ──► PostgreSQL/PGVector（未来扩展）
        │
        └──► MemoryIndex ──► 记忆索引管理
```

### 6.3 原子写入策略

```python
async def _write_atomic(self, path: Path, data: bytes) -> None:
    """原子写入"""
    temp_path = path.with_suffix(path.suffix + ".tmp")
    temp_path.write_bytes(data)
    temp_path.replace(path)  # POSIX 原子操作
```

### 6.2 错误码

| 错误码 | 说明 | 触发场景 |
| ------ | ---- | -------- |
| `Store_001` | 存储后端失败 | 数据库或文件系统操作失败 |
| `Store_002` | 会话不存在 | 尝试访问不存在的会话 |
| `Store_003` | 存储配额超限 | 存储大小超过限制 |
| `Store_004` | 数据损坏检测 | 数据完整性校验失败 |
