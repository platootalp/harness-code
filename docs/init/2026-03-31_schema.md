## 1. 概述

### 1.1 文档目的

本文档定义 Mozi AI Coding Agent 系统的数据库 Schema 设计，包括 SQLite 会话存储和向量数据库（Milvus）记忆存储的表结构、索引设计、以及数据约束。

### 1.2 存储架构

```
┌─────────────────────────────────────────────────────────────┐
│                        存储层架构                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │   SQLite    │  │   Milvus    │  │   本地      │        │
│  │ (会话/消息)  │  │  (向量存储)  │  │  (产物文件) │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
│                                                             │
│  WAL 模式        向量检索           原子写入                  │
│  多进程并发       相似度搜索        分块存储                 │
└─────────────────────────────────────────────────────────────┘
```

| 数据类型  | 存储方案        | 说明                 |
| --------- | --------------- | -------------------- |
| 会话/消息 | SQLite WAL 模式 | 多进程并发，崩溃恢复 |
| 向量记忆  | Milvus          | 高性能相似度检索     |
| 产物文件  | 本地文件系统    | 大结果分块存储       |

## 2. SQLite Schema

### 2.1 数据库配置

```sql
-- 启用 WAL 模式以支持更好的并发
PRAGMA journal_mode=WAL;

-- 设置 busy_timeout 以处理锁等待
PRAGMA busy_timeout=5000;

-- 启用外键约束
PRAGMA foreign_keys=ON;
```

### 2.2 sessions 表

会话表，存储用户会话的元数据。

```sql
CREATE TABLE sessions (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL DEFAULT '',
    working_dir TEXT NOT NULL DEFAULT '',
    status TEXT NOT NULL DEFAULT 'active'
        CHECK (status IN ('active', 'idle', 'archived', 'expired')),
    metadata TEXT NOT NULL DEFAULT '{}',
    user_id TEXT,
    tags TEXT NOT NULL DEFAULT '[]',
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    last_active_at TEXT NOT NULL
);

COMMENT ON TABLE sessions IS '用户会话表';
COMMENT ON COLUMN sessions.id IS '会话唯一标识(UUID v4)';
COMMENT ON COLUMN sessions.name IS '会话名称';
COMMENT ON COLUMN sessions.working_dir IS '工作目录';
COMMENT ON COLUMN sessions.status IS '会话状态: active/idle/archived/expired';
COMMENT ON COLUMN sessions.metadata IS '会话元数据(JSON)';
COMMENT ON COLUMN sessions.user_id IS '用户ID';
COMMENT ON COLUMN sessions.tags IS '会话标签(JSON数组)';
COMMENT ON COLUMN sessions.created_at IS '创建时间(ISO 8601)';
COMMENT ON COLUMN sessions.updated_at IS '更新时间(ISO 8601)';
COMMENT ON COLUMN sessions.last_active_at IS '最后活跃时间(ISO 8601)';
```

#### 索引设计

```sql
-- 按状态列出会话的高频查询
CREATE INDEX idx_sessions_status ON sessions(status);

-- 按用户ID筛选的高频查询
CREATE INDEX idx_sessions_user_id ON sessions(user_id);

-- 按最后活跃时间排序的查询
CREATE INDEX idx_sessions_last_active ON sessions(last_active_at);

-- 复合索引: 用户 + 状态
CREATE INDEX idx_sessions_user_status ON sessions(user_id, status);
```

### 2.3 messages 表

消息表，存储会话中的每条消息。

```sql
CREATE TABLE messages (
    id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL,
    role TEXT NOT NULL
        CHECK (role IN ('system', 'user', 'assistant', 'tool')),
    content TEXT NOT NULL DEFAULT '',
    timestamp TEXT NOT NULL,
    tool_call_id TEXT,
    attachment_path TEXT,
    metadata TEXT NOT NULL DEFAULT '{}',
    streaming_content TEXT NOT NULL DEFAULT '',
    is_streaming INTEGER NOT NULL DEFAULT 0,
    FOREIGN KEY (session_id) REFERENCES sessions(id) ON DELETE CASCADE
);

COMMENT ON TABLE messages IS '会话消息表';
COMMENT ON COLUMN messages.id IS '消息唯一标识(UUID v4)';
COMMENT ON COLUMN messages.session_id IS '所属会话ID(FK)';
COMMENT ON COLUMN messages.role IS '消息角色: system/user/assistant/tool';
COMMENT ON COLUMN messages.content IS '消息内容';
COMMENT ON COLUMN messages.timestamp IS '消息时间戳(ISO 8601)';
COMMENT ON COLUMN messages.tool_call_id IS '关联的工具调用ID';
COMMENT ON COLUMN messages.attachment_path IS '大结果文件路径(可选)';
COMMENT ON COLUMN messages.metadata IS '消息元数据(JSON)';
COMMENT ON COLUMN messages.streaming_content IS '流式输出渐进内容';
COMMENT ON COLUMN messages.is_streaming IS '是否正在流式输出(0/1)';
```

#### 索引设计

```sql
-- 按 session_id 查找消息的高频查询
CREATE INDEX idx_messages_session_id ON messages(session_id);

-- 按时间戳排序的消息查询
CREATE INDEX idx_messages_timestamp ON messages(timestamp);

-- 复合索引: 会话 + 时间排序
CREATE INDEX idx_messages_session_time ON messages(session_id, timestamp);

-- 工具调用结果查询
CREATE INDEX idx_messages_tool_call ON messages(tool_call_id) WHERE tool_call_id IS NOT NULL;
```

### 2.4 attachments 目录

附件存储（非数据库表，使用文件系统）。

```
~/.mozi/attachments/
├── {session_id}/
│   ├── {message_id}_tool_result_0.bin
│   ├── {message_id}_tool_result_1.bin
│   └── ...
```

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 存储路径 | string | `~/.mozi/attachments/{session_id}/{message_id}_tool_result_{index}.bin` |
| 存储阈值 | int | 默认 4096 字节（`session.tool_call_file_threshold`） |
| 编码格式 | binary | 原始二进制或 JSON 压缩格式 |

### 3.2 索引设计

```json
{
  "indexes": [
    {
      "field_name": "embedding",
      "index_type": "HNSW",
      "metric_type": "COSINE",
      "params": {
        "M": 16,
        "efConstruction": 256
      }
    },
    {
      "field_name": "session_id",
      "index_type": "STL_SORT"
    },
    {
      "field_name": "memory_type",
      "index_type": "STL_SORT"
    },
    {
      "field_name": "status",
      "index_type": "STL_SORT"
    }
  ]
}
```

| 索引类型 | 字段 | 说明 |
| -------- | ---- | ---- |
| HNSW | embedding | 高性能向量相似度检索 |
| STL_SORT | session_id | 按会话过滤 |
| STL_SORT | memory_type | 按记忆类型过滤 |
| STL_SORT | status | 按状态过滤 |

### 3.3 搜索参数

```json
{
  "search_params": {
    "metric_type": "COSINE",
    "params": {
      "ef": 128
    }
  }
}
```

| 参数 | 值 | 说明 |
| ---- | --- | ---- |
| metric_type | COSINE | 余弦相似度 |
| ef | 128 | HNSW 搜索参数，越大越精确但越慢 |

## 4. 数据模型映射

### 4.1 Python 数据模型

#### Session

```python
@dataclass
class Session:
    """会话结构"""
    id: str
    name: str = ""
    working_dir: str = ""
    status: SessionStatus = SessionStatus.ACTIVE
    metadata: dict[str, Any] = field(default_factory=dict)
    user_id: str | None = None
    tags: list[str] = field(default_factory=list)
    created_at: datetime = field(default_factory=datetime.now)
    updated_at: datetime = field(default_factory=datetime.now)
    last_active_at: datetime = field(default_factory=datetime.now)
```

#### Message

```python
@dataclass
class Message:
    """消息结构"""
    id: str
    session_id: str
    role: MessageRole
    content: str = ""
    timestamp: datetime = field(default_factory=datetime.now)
    tool_call_id: str | None = None
    attachment_path: str | None = None
    metadata: dict[str, Any] = field(default_factory=dict)
    streaming_content: str = ""
    is_streaming: bool = False
```

#### MemoryBlock

```python
@dataclass
class MemoryBlock:
    """记忆块"""
    id: str
    session_id: str
    content: str
    memory_type: MemoryType
    embedding: list[float] | None = None
    importance: float = 0.5
    status: SessionStatus = SessionStatus.ACTIVE
    created_at: datetime = field(default_factory=datetime.now)
    accessed_at: datetime = field(default_factory=datetime.now)
    metadata: dict[str, Any] = field(default_factory=dict)
```

### 4.2 枚举类型

```python
class SessionStatus(Enum):
    """会话状态"""
    ACTIVE = "active"       # 活跃会话
    IDLE = "idle"           # 空闲会话
    ARCHIVED = "archived"   # 已归档会话
    EXPIRED = "expired"     # 已过期会话


class MessageRole(Enum):
    """消息角色"""
    SYSTEM = "system"
    USER = "user"
    ASSISTANT = "assistant"
    TOOL = "tool"


class MemoryType(Enum):
    """记忆类型"""
    SHORT_TERM = "short_term"    # 短期记忆（内存，非持久化）
    SEMANTIC = "semantic"        # 语义记忆
    EPISODIC = "episodic"        # 情景记忆
    PROCEDURAL = "procedural"     # 程序记忆
```

## 5. SQL 与代码映射

### 5.1 JSON 字段序列化

SQLite 不支持 JSON 类型，以下字段以 JSON 字符串存储：

| 字段 | SQLite 存储 | Python 类型 |
| ---- | ----------- | ---------- |
| `sessions.metadata` | TEXT | `dict[str, Any]` |
| `sessions.tags` | TEXT | `list[str]` |
| `messages.metadata` | TEXT | `dict[str, Any]` |
| `memory_blocks.metadata` | JSON (Milvus) | `dict[str, Any]` |

### 5.2 日期时间格式

所有日期时间使用 **ISO 8601** 格式（UTC）存储：

```
2026-04-01T12:00:00.000000Z
```

### 5.3 NULL 值处理

| 字段 | 可空 | 说明 |
| ---- | ---- | ---- |
| `sessions.user_id` | YES | 匿名会话 |
| `messages.tool_call_id` | YES | 非工具消息 |
| `messages.attachment_path` | YES | 小结果内联存储 |
| `memory_blocks.embedding` | YES | 短期记忆无需 embedding |

## 6. 完整性约束

### 6.1 外键约束

```sql
-- messages.session_id -> sessions.id
-- 级联删除: 删除会话时自动删除所有消息
FOREIGN KEY (session_id) REFERENCES sessions(id) ON DELETE CASCADE
```

### 6.2 CHECK 约束

```sql
-- sessions.status
CHECK (status IN ('active', 'idle', 'archived', 'expired'))

-- messages.role
CHECK (role IN ('system', 'user', 'assistant', 'tool'))

-- messages.is_streaming
CHECK (is_streaming IN (0, 1))
```

### 6.3 NOT NULL 约束

除上述可空字段外，所有字段均为 NOT NULL，并设置合理的默认值：

| 表 | 字段 | 默认值 |
| -- | ---- | ------ |
| sessions | name | '' |
| sessions | working_dir | '' |
| sessions | status | 'active' |
| sessions | metadata | '{}' |
| sessions | tags | '[]' |
| messages | content | '' |
| messages | metadata | '{}' |
| messages | streaming_content | '' |
| messages | is_streaming | 0 |

## 7. 迁移策略

### 7.1 迁移文件结构

```
mozi/infrastructure/
└── storage/
    └── migrations/
        ├── __init__.py
        ├── manager.py
        └── versions/
            ├── 001_initial_schema.sql
            ├── 002_add_memory_blocks.sql
            └── 003_...
```

### 7.2 迁移命名

| 版本 | 文件 | 说明 |
| ---- | ---- | ---- |
| 001 | `001_initial_schema.sql` | 初始 Schema（sessions, messages） |
| 002 | `002_add_memory_blocks.sql` | 新增 memory_blocks Collection |

### 7.3 迁移规则

1. 迁移文件按序号执行
2. 每个迁移文件包含 UP 和 DOWN 脚本
3. 迁移前自动备份数据
4. 迁移失败自动回滚
