## Migration Guide

### From v0.1.0

This is the first stable release. To get started:

```bash
# Clone or update the repository
git clone https://github.com/your-org/mozi.git
cd mozi

# Install dependencies
uv sync

# Verify installation
mozi --version
```

## Known Limitations

1. **Vector DB**: Requires external Milvus instance for full vector search capabilities
2. **IDE Plugin**: IDE integration not yet implemented
3. **REST API**: REST API layer is foundational, not production-ready
