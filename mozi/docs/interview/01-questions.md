# AI Coding Agent 深度面试题（P8-P9 级）

> 本面试题针对 AI Coding Agent 项目的核心技术模块设计，按难度递进，分为：基础理解 → 深度原理 → 系统设计 → 实战攻防 四个维度。

---

## 模块一：多智能体编排与自适应路由

### L1 基础理解

**Q1: 请解释 Orchestrator-Worker 架构中 Orchestrator 的核心职责是什么？它与传统分布式调度器有什么本质区别？**

**Q2: 你提到引入了 ReAct 循环，能画一下 ReAct 的执行流程吗？Agent 在什么情况下会退出循环？**

**Q3: "智能澄清与风险评估机制"具体指什么？澄清是用户主动触发还是 Agent 主动发起？**

### L2 技术深度

**Q4: 复杂度-风险双维路由算法中，"复杂度"和"风险"分别是如何量化的？请举例说明一个具体任务在这两个维度上的评估过程。**

**Q5: QUICK/DEEP/STRATEGIC 三种执行模式分别适用于什么场景？模式切换的触发条件是什么？有没有出现过模式选择错误导致的问题？**

**Q6: 5类领域专家 Agent 具体是哪5类？它们之间的职责边界是如何划分的？如果两个 Agent 对同一个子任务都有处理能力，冲突如何解决？**

### L3 系统设计

**Q7: 如果 Orchestrator 本身成为了性能瓶颈，你会如何优化？能否设计一个去中心化的编排方案？**

**Q8: 任务完成率提升 40% 是如何衡量的？有没有建立漏斗分析体系来定位瓶颈环节？**

## 模块二：DAG 任务分解与调度

### L1 基础理解

**Q9: 你提到的"四维度任务校验（完整性/原子性/独立性/可验证性）"具体定义是什么？一个不符合某个维度的任务长什么样？**

**Q10: DAG 依赖管理中，环形依赖如何检测和处理？如果 LLM 生成的任务分解存在循环依赖，系统如何应对？**

### L2 技术深度

**Q11: 拓扑排序生成并行执行计划的具体算法是什么？如何保证拓扑排序的结果是最优的调度顺序？**

**Q13: 长任务的可中断/恢复/取消机制是如何实现的？中断点的选择策略是什么？如何保证中断后状态一致性？**

### L3 系统设计

**Q14: 如果让你设计一个任务熔断机制，防止异常任务耗尽整个系统的调度资源，你会怎么做？**

**Q15: 后台任务与会话 TODOList 联动机制中，任务状态同步的实时性如何保证？有没有遇到过状态不一致的问题？**
