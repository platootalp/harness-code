## 1. 概述

### 1.1 模块名称

Ingress（接入层）

### 1.2 职责

Ingress 模块是 Mozi 系统的用户入口，负责接收用户输入、解析命令、管理 REPL 交互循环，并将请求路由到编排层（Orchestration）。

### 1.3 核心能力

| 能力 | 说明 |
| ---- | ---- |
| REPL 交互 | 支持交互式对话循环，实时响应用户输入 |
| 命令模式 | 支持离线命令执行（`mozi do "任务"`） |
| 会话管理 | 支持创建、继续、列表、删除会话 |
| 输出格式化 | 结构化输出、错误提示、进度展示 |
| 事件发布 | 通过 EventBus 将用户消息发布到编排层 |

## 2. 核心问题与解决方案

### 2.1 用户输入多样化

**问题描述**：用户通过不同方式与系统交互——交互式 REPL 和离线命令模式。这两种模式有不同的输入特性和响应期望。

**挑战**：如何设计统一入口支持两种模式，同时保持各模式的特性和用户体验。REPL 需要维护会话状态，命令模式需要一次性处理。

**解决方案**：实现双入口设计，ReplCLI 处理交互式会话，CommandCLI 处理离线命令。通过 CliMode 枚举区分模式，共享底层 EventBus 通信机制。

### 2.2 输出格式化与用户体验

**问题描述**：需要结构化展示执行结果、错误信息和进度。输出需要友好易懂，同时支持详细模式。

**挑战**：如何平衡美观性和信息密度。彩色输出在某些环境可能不支持。大量输出时的性能也需要考虑。

**解决方案**：OutputFormatter 实现统一的输出格式化，支持普通输出、错误输出、进度条等多种形式。可以通过 verbose 参数控制详细程度。

### 2.3 会话生命周期管理

**问题描述**：作为用户与系统交互的入口，需要管理会话的完整生命周期。包括创建、继续、列表、删除等操作。

**挑战**：会话状态需要持久化和恢复。多会话并发时需要正确隔离。会话清理和过期处理也是问题。

**解决方案**：通过 SessionManager 接口管理会话生命周期。EventBus 集成实现与 Orchestrator 的解耦通信。会话操作通过统一命令接口暴露。

### 2.4 命令解析与参数处理

**问题描述**：需要解析用户输入的命令和参数。不同命令有不同参数格式和验证规则。

**挑战**：命令语法需要直观易记，同时支持足够灵活性。参数验证需要友好错误提示。未知命令处理也需要考虑。

**解决方案**：commands.py 定义命令解析逻辑，支持 do/repl/session 等命令。使用 parse_command() 统一解析入口，验证后转换为 UserInput 结构。

### 2.5 REPL 状态管理与历史

**问题描述**：REPL 模式需要维护交互状态，支持多会话切换、命令历史查看和补全。

**挑战**：状态管理不能影响主流程响应速度。历史命令存储需要持久化。跨会话状态隔离也是问题。

**解决方案**：ReplCLI 维护内部状态机处理交互循环。读取历史命令通过 readline 或类似机制。stop() 方法支持优雅退出。

## 3. 数据模型与状态机

### 3.1 核心类型定义

```python
from dataclasses import dataclass
from enum import Enum
from typing import Optional


class CliMode(Enum):
    """CLI 运行模式"""
    REPL = "repl"       # 交互式 REPL 模式
    COMMAND = "command" # 单次命令模式


class SessionAction(Enum):
    """会话操作类型"""
    CREATE = "create"
    CONTINUE = "continue"
    LIST = "list"
    DELETE = "delete"


@dataclass
class UserInput:
    """用户输入结构"""
    mode: CliMode
    content: str
    session_id: Optional[str] = None
    verbose: bool = False


@dataclass
class CliResult:
    """CLI 执行结果"""
    success: bool
    content: str
    session_id: Optional[str] = None
    error: Optional[str] = None
```

## 5. 接口、交互与流程

### 5.1 CLI 接口定义

```python
class BaseCLI(ABC):
    """CLI 抽象基类"""

    def __init__(self, output: OutputFormatter) -> None:
        self._output = output

    @abstractmethod
    async def run(self, input_data: UserInput) -> CliResult:
        """执行 CLI 命令"""
        ...


class ReplCLI(BaseCLI):
    """REPL 交互式 CLI 实现"""

    async def run(self, input_data: UserInput) -> CliResult:
        """启动 REPL 循环"""
        self._running = True
        session = await self._session_manager.create()
        try:
            while self._running:
                line = await self._read_line()
                if line is None:
                    break
                result = await self._process_line(line, session.id)
                self._output.print(result)
            return CliResult(success=True, content="Session ended")
        except MoziError as e:
            return CliResult(success=False, content="", error=str(e))

    def stop(self) -> None:
        """停止 REPL 循环"""
        self._running = False


class CommandCLI(BaseCLI):
    """命令模式 CLI 实现"""

    async def run(self, input_data: UserInput) -> CliResult:
        """执行单次命令"""
        if input_data.session_id:
            session_id = input_data.session_id
        else:
            session = await self._session_manager.create()
            session_id = session.id

        await self._event_bus.publish(
            "user_message",
            {
                "session_id": session_id,
                "content": input_data.content,
                "verbose": input_data.verbose,
            },
        )
        result = await self._wait_for_result(session_id)
        return CliResult(
            success=result.get("success", False),
            content=result.get("content", ""),
            session_id=session_id,
            error=result.get("error"),
        )
```

### 5.2 命令行参数

| 命令 | 参数 | 说明 |
| ---- | ---- | ---- |
| `mozi` | - | 启动 REPL 交互模式 |
| `mozi do` | `<task>` | 执行单次命令 |
| `mozi session` | `create/list/continue` | 会话管理 |
| `mozi -v` | - | 启用详细输出 |

### 5.3 EventBus 事件

| 事件名 | 方向 | Payload | 说明 |
| ---- | ---- | ------- | ---- |
| `user_message` | Ingress -> Orchestration | `{"session_id", "content", "verbose"}` | 用户消息 |
| `agent_response` | Orchestration -> Ingress | `{"session_id", "content", "success"}` | Agent 响应 |
| `tool_execution` | Orchestration -> Ingress | `{"tool", "args", "result"}` | 工具执行结果 |
| `session_created` | Orchestration -> Ingress | `{"session_id"}` | 会话创建事件 |
| `error` | Orchestration -> Ingress | `{"session_id", "error", "code"}` | 错误事件 |

## 6. 边界与契约

### 6.1 错误码定义

> **说明**：Ingress 模块的错误处理遵循统一异常体系。

| 错误码 | 错误类型 | 说明 |
| ------ | -------- | ---- |
| `INGRESS_001` | CliParseError | CLI 参数解析失败 |
| `INGRESS_002` | CommandNotFoundError | 命令不存在 |
| `INGRESS_003` | SessionNotFoundError | 会话不存在 |
| `INGRESS_004` | InvalidCommandError | 无效命令 |
| `INGRESS_005` | OutputFormatError | 输出格式化失败 |

### 6.2 API 契约

#### 6.2.1 BaseCLI.run()

**请求**：
```python
async def run(self, input_data: UserInput) -> CliResult
```

**响应**：
- `CliResult`: 包含 success、content、session_id、error 字段

**错误**：
- `INGRESS_001`: 当参数解析失败时抛出
- `INGRESS_002`: 当命令不存在时抛出
- `INGRESS_004`: 当命令无效时抛出

### 6.3 约束与限制

| 约束 | 限制值 | 说明 |
| ---- | ------ | ---- |
| 命令最大长度 | 10000 字符 | 防止过长的输入 |
| 历史命令最大条数 | 1000 | readline 历史限制 |
| REPL 空闲超时 | 3600 秒 | 可通过配置调整 |

## 7. 实现细节

### 7.1 命令解析

```python
def parse_command(input_str: str) -> UserInput:
    """解析用户输入为 UserInput 结构"""
    parts = input_str.strip().split()
    if not parts:
        raise CliParseError("Empty input")

    command = parts[0]

    if command == "do":
        # src do "task"
        task = " ".join(parts[1:])
        return UserInput(mode=CliMode.COMMAND, content=task)

    elif command == "repl":
        # src repl
        return UserInput(mode=CliMode.REPL, content="")

    elif command == "session":
        # src session create/list/continue/delete
        if len(parts) < 2:
            raise CliParseError("Missing session action")
        action = parts[1]
        session_id = parts[2] if len(parts) > 2 else None
        return UserInput(
            mode=CliMode.COMMAND,
            content=f"session {action}",
            session_id=session_id,
        )

    else:
        # 默认作为单次命令处理
        return UserInput(mode=CliMode.COMMAND, content=input_str)
```

### 7.2 输出格式化

```python
class OutputFormatter:
    """输出格式化器"""

    def __init__(self, use_color: bool = True, verbose: bool = False) -> None:
        self._use_color = use_color
        self._verbose = verbose

    def print(self, result: CliResult) -> None:
        """打印结果"""
        if not result.success and result.error:
            self._print_error(result.error)
        else:
            self._print_content(result.content)

    def _print_content(self, content: str) -> None:
        """打印普通内容"""
        print(content)

    def _print_error(self, error: str) -> None:
        """打印错误信息"""
        if self._use_color:
            print(f"\033[91mError: {error}\033[0m")
        else:
            print(f"Error: {error}")

    def print_progress(self, current: int, total: int, message: str) -> None:
        """打印进度条"""
        bar_length = 30
        percent = current / total
        filled = int(bar_length * percent)
        bar = "=" * filled + "-" * (bar_length - filled)
        print(f"\r[{bar}] {int(percent*100)}% {message}", end="")
```
