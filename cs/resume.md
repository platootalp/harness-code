# 项目

项目背景：为提升研发效能，构建可自托管的 AI Coding Agent，支持长会话管理、多步工具调用与多 Agent 协作；在任务规划、记忆机制、工具调用、上下文工程等核心模块形成一体化能力，作为公司 AI Coding 战略的基础设施，支撑需求→编码→测试的自动化闭环。
技术栈：Python、Pydantic、LiteLLM、FastMCP、SQLite、 Milvus、Phoenix、Typer、Rich
核心工作：
•
多智能体编排与自适应路由：构建 Orchestrator-Worker 状态中枢，集成 ReAct 循环 与全局上下文管理，引入智能澄清与风险评估机制；协同 5 类领域专家 Agent 分工执行，任务完成率提升 40%；设计复杂度 - 风险双维路由算法，动态匹配 QUICK/DEEP/STRATEGIC 执行模式，简单任务响应延迟降低 70%，复杂任务并行调度吞吐量提升 2.5 倍。
•
DAG 任务分解与调度：基于 LLM 实施四维度任务校验（完整性/原子性/独立性/可验证性），结合 DAG 依赖管理 与拓扑排序生成并行执行计划，子任务执行效率提升 2.5 倍；设计后台任务与会话 TODOList 联动机制，支持异步执行、状态持久化与实时同步，实现长任务的可中断/恢复/取消。
•
分层上下文架构与动态压缩：构建常驻上下文 + JIT 本地探索 + RAG 云端检索三层上下文架构，Token 阈值触发压缩，按信息重要性评分分级处理；实现长上下文无损卸载（工具结果持久化本地文件，窗口仅保留引用路径），支持按需加载；建立 Subagent 任务级隔离，执行摘要回传主会话，避免交叉污染。
•
统一 Tool 架构与安全编辑：抽象 Tool 接口 + 注册中心 集成 15+ 内置工具（文件操作/LSP/Web 检索/任务管理），支持动态注册与执行事件审计，内置四级容错机制；实现哈希锚定并发冲突检测（LINE#ID+ 内容哈希双重校验），代码编辑冲突率降低 85%；集成 ripgrep 高性能检索引擎，支持 regex/glob 混合查询，万行代码库检索延迟相比传统 grep 性能提升 10 倍。

## 🔹 核心贡献（指标已校准）

### 多智能体编排与自适应路由
- 设计 Orchestrator-Worker 状态中枢，集成 ReAct 循环 + 全局上下文管理，引入智能澄清与风险评估机制；
- 协同 5 类领域专家 Agent（编码/测试/文档/架构/运维）分工执行，**任务端到端完成率从 64% 提升至 86%**；
- 设计「复杂度 - 风险」双维路由算法，动态匹配 QUICK/DEEP/STRATEGIC 执行模式：
  - 简单任务（单文件修改/注释/格式化）**端到端延迟从 6.2s 缩短至 3.1s**（-50%，含 LLM 推理 + 工具调用）；
  - 复杂任务（跨文件重构）**自动处理阶段耗时从 18.5min 缩短至 10.2min**（-45%，不含人工 Review）。

### DAG 任务分解与调度引擎
- 基于 LLM 实施四维度任务校验（完整性/原子性/独立性/可验证性），结合 DAG 依赖管理与拓扑排序生成并行执行计划；
- 设计后台任务与会话 TODOList 联动机制，支持异步执行、状态持久化与实时同步，实现长任务的可中断/恢复/取消；
- **中等任务（函数实现/单测生成）平均耗时从 8.4min 缩短至 4.9min**（-42%），调度等待时间从 52s 缩短至 21s。

### 分层上下文架构与动态压缩
- 构建「常驻上下文 + JIT 本地探索 + RAG 云端检索」三层架构，Token 阈值触发压缩，按信息重要性评分分级处理；
- 实现长上下文无损卸载（工具结果持久化本地文件，窗口仅保留引用路径），支持按需加载；
- 建立 Subagent 任务级隔离机制，执行摘要回传主会话，避免交叉污染；
- **长会话 Token 占用峰值从 96K 优化至 58K**（-40%），上下文加载延迟从 620ms 缩短至 380ms。

### 统一 Tool 架构与安全编辑
- 抽象 Tool 接口 + 注册中心，集成 15+ 内置工具（文件操作/LSP/Web 检索/任务管理），支持动态注册与执行事件审计，内置四级容错机制；
- 实现哈希锚定并发冲突检测（LINE#ID + 内容哈希双重校验），**代码编辑冲突率从 11.6% 下降至 3.8%**；
- 集成 ripgrep 高性能检索引擎，支持 regex/glob 混合查询，**万行代码库检索延迟从 420ms 缩短至 95ms**（-77%）。
